# Rubin-ASKAP-project
The aim of this project is to cross-match optical transient signals with radio emission detected by Southern Hemisphere radio surveys. 

This is an initial analysis of the COSMOS sky region to investigate whether any ZTF alerts have corresponding radio emission detected by ASKAP’s EMU survey. We have developed a workflow combining seven years of ZTF optical alerts with ASKAP’s EMU survey. Using Fink, we access ZTF alerts and apply NWAY, a probabilistic cross-matching tool that accounts for source density and sky area to distinguish genuine associations from chance alignments.
